# Тексты к записям первой части

Здесь лежат `lesson-<номер>.json` с номером урока и массивом исходных абзацев.
Огласовки, пунктуация и Unicode сохраняются как в присланном документе.
DOCX импортируется скриптом, а не загружается сюда под видом JSON.
