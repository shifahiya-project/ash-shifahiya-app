# Полная замена второй части курса

Редакция от 28 октября 2026 года включает 105 уроков шести книг, 2823 статьи,
253 раздела чтения, 3618 пар текста и перевода и 1693 контекста словаря.

## Подготовка и импорт

```sh
python scripts/prepare-part2-reading.py corrected-reading.docx reading.json --update-listening
npm run part2:import -- corrected-glossary.json reading.json
```

Первый скрипт читает DOCX стандартной библиотекой Python. Номера источника
считают и заголовки, и пары внутри урока. Он проверяет количество уроков,
разделов и фрагментов; не меняет их пунктуацию, границы или Unicode.

Флаг `--update-listening` заменяет только существующие тексты второй части
рядом с 61 аудиозаписью. Арабские абзацы берутся из того же DOCX без нормализации;
записи, длительности и состав каталога сохраняются. Версия URL текста меняется
по SHA-256 нового JSON, чтобы прежний кэш не показывал старую редакцию.

Импортёр распознаёт schemaVersion 2 нового словаря. Все 1693 контекста и переводы
сверяются с указанными исходными парами; каждая статья должна ссылаться на свой
контекст. В учебных данных применяется NFC. Более подробные категории словаря
сопоставляются с существующими категориями движка; оригинальная статья целиком
сохраняется в `source`, включая формы глагола и редакторские примечания.

## Адреса повторения и прогресс

Порядок слов берётся из нового словаря. Он больше не определяет адрес повторения:
для этого используется `reviewIndex`. В исходной перезаливке 2606 слов были
однозначно сопоставлены по арабской словарной форме и пересекающемуся значению;
217 получили новые номера после прежнего диапазона своего урока. Удалённые
карточки не переназначаются новым словам. Их прежние записи остаются в хранилище.

`reviewIndexCeiling` удерживает верхнюю границу зарезервированных адресов и при
следующих перезаливках. Повторный импорт той же статьи по source.id сохраняет
адрес. Формат ключей `p2-lesson-N-word-I-direction` не меняется.

Завершённые уроки, доступ к следующим частям и история аудио не сбрасываются.
Результаты контекстных работ хранятся в `part2Results` вместе с редакцией
и числом заданий. Старые числовые результаты получают прежние знаменатели
из `content/part2/legacy-question-counts.ts` (состояние до перезаливки, ee0c027).
Если размер неизвестен, интерфейс показывает баллы без выдуманного знаменателя.
На карточке выводится результат последней завершённой редакции: прежние 39/39
не превращаются в 39/35, а новое прохождение на 35/35 не сравнивается со старыми
39 баллами. Лучшие результаты предыдущих редакций остаются в истории.
Повтор той же работы может только повысить её результат. Совместимые числовые
ключи `part2Scores` продолжают открывать следующие уроки и части курса.
История переносится синхронизацией и резервной копией формата 6; форматы 1–5
продолжают загружаться. Старое устройство или старая копия не подменяют новый
результат большим числом баллов из другой редакции.

У незавершённой сессии изменившейся редакции нельзя сохранять индекс вопроса:
под этим индексом теперь может быть другое слово. Поэтому исходная сессия
архивируется в `archivedSession`, а новая начинается с первого круга карточек.
Её собственные ответы и счёт не смешиваются с прежним набором заданий.
`contentRevision` сохраняется при каждом шаге; возобновление уже новой сессии
не запускает её снова. Архив переносится существующим экспортом и синхронизацией.

## Проверки

```sh
npm test
npm run lint
npm run build:static
npm run smoke
```

`tests/part2-revision.test.mjs` проверяет полноту комплекта, связь всех слов
с конкретными парами чтения, уникальность адресов и архивирование прежней сессии.
Прочие проверки второй части продолжают проверять оба направления перевода,
контекстные задания, доступ к урокам и прежние форматы прогресса.
`tests/part2-results.test.mjs` проверяет прежние знаменатели, независимые результаты
редакций, повторное прохождение, синхронизацию и перенос истории через хранилище.
