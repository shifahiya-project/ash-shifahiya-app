# Тексты и записи уроков

Новые материалы хранятся отдельно, по номеру урока:

- `public/audio/shifahiya-1/lesson-91.mp3` — запись;
- `public/text/shifahiya-1/lesson-91.json` — текст;
- `public/text-and-audio/catalog.json` — список доступных пар.

Для второй части («Чтение») используются `public/audio/reading-2/lesson-1.mp3`
и `public/text/reading-2/lesson-1.json`. В каталоге такая запись имеет
`courseId: 2` и `courseTitle: "Чтение"`. Номер урока относится к своей части;
одинаковые номера разных частей не пересекаются.

Плеер открывается кнопкой «Текст и аудио» в доступном уроке. Записи и тексты
других уроков при этом не загружаются. Позиция, скорость и настройки текста
сохраняются отдельно для каждого урока. Скачивание урока собирает один HTML
со встроенной записью и текстом; его можно открыть без интернета.
Уроки 87, 88, 91, 92 и 95–100 находятся в общем списке этого плеера.
Для «Чтения» добавлены уроки 1–14 и 16–30; урок 15 пропущен.
Плеер показывает список записей своей части;
ссылка второй части имеет вид `text-and-audio.html?lesson=1&course=2`.
Первоначальный автономный пилот 87–88 также сохранён по прежнему адресу.

Слова и задания, а также текст и аудио имеют отдельные отметки прохождения.
После занятия нажмите «Текст и аудио пройдены» в плеере. До этого урок остаётся
в компактном списке курса, даже если слова и задания уже пройдены. Отметку можно
отменить. Достижение конца записи само по себе не ставит отметку: текст и аудио
проходятся в своём темпе.
Во второй части это отдельный этап после слов, заданий и чтения; доступ к
следующему учебному уроку по-прежнему определяется прохождением чтения.

На сайте отметки входят в резервную копию и синхронизацию общего прогресса.
Скачанный HTML сохраняет отметку только в своём браузерном хранилище;
автоматически перенести её на сайт нельзя. После занятия в скачанном файле
отметьте урок отдельно на сайте. Позиции 87–88 из прежнего пилота продолжают
работать в общем плеере, поскольку ключи их хранения совпадают.
Позиции и отметки второй части хранятся под собственными ключами
`shifahiya-p2-listening-{id}-v1` и `shifahiya-p2-listening-progress-v1`.
Резервная копия версии 4 содержит `part2Listening` и `listeningReviews`.
Копии версий 1–3 принимаются; отсутствующая в старой копии история повторений
сохраняется на устройстве. Копии версий 1 и 2 также сохраняют местные отметки
аудио второй части, если в старой копии их нет.

## Повторение аудио

После первого изучения аудиозаписи второй или следующей части начинается цикл
из семи повторений. При занятиях по графику это дни 1, 3, 7, 21, 60, 180 и 365.
Интервалы 1, 2, 4, 14, 39, 120 и 185 дней считаются от фактического занятия:
просрочка сдвигает последующие даты. После семи повторений цикл заканчивается.

На главной «Повторить аудио» открывает очередь готовых к повторению записей.
Плеер показывает график и кнопку «Повторение пройдено». Раннее прослушивание
или обычное достижение конца записи не продвигает расписание. Одна отметка
закрывает только очередное повторение. Уже пройденные записи используют дату
своей сохранённой отметки как дату изучения.

Истории всех частей со второй хранятся в `shifahiya-listening-reviews-v1`
под ключами `часть:урок`. Отмена исходной отметки приостанавливает расписание;
восстановление отметки возвращает прежнюю историю. Первая часть повторений
аудио не получает. Новые части включаются в очередь по `courseId` каталога.
Синхронизация сохраняет пройденные этапы, даже если отметку отменили на устройстве
с устаревшей историей. Одновременные повторения одного этапа не удваивают счётчик.
Позиция в очередном повторении хранится отдельно от первого изучения.
Скачанный HTML поддерживает тот же график и сохраняет его в своём хранилище;
переносить отметки со скачанного файла на сайт по-прежнему нужно отдельно.

## Добавить DOCX и WAV

В корне репозитория, с установленными Python 3 и FFmpeg:

```bash
python scripts/import-listening.py 93 '/path/to/урок 93.docx' '/path/to/урок 93.wav'
python scripts/import-listening.py 11 '/path/to/урок_011.txt' '/path/to/011_2.wav' --course 2
```

Скрипт извлекает текст из DOCX без Unicode-нормализации и исправления огласовок,
сохраняет абзацы, пробелы, табуляцию и переносы строк. MP3 кодируется с битрейтом
96 кбит/с, с сохранением каналов исходной записи. Метаданные записи не переносятся.
Существующие уроки не перезаписываются; таблицы, сноски и отслеживаемые удаления
требуют ручной проверки. Исходные документы и WAV остаются у автора, в репозиторий
попадают текст и MP3. При необходимости файлы можно прислать в чат для обработки.
TXT читается как UTF-8; сигнатура BOM убирается, пустые строки отделяют абзацы.
Буквы, порядок огласовок, пунктуация и переносы внутри абзаца сохраняются.
`sourceSha256` содержит контрольную сумму исходного файла.

## Загрузить напрямую через GitHub

Загрузите MP3 в папку `public/audio/shifahiya-1` под именем `lesson-93.mp3`.
Добавьте в `public/text/shifahiya-1` файл `lesson-93.json`:

```json
{
  "lessonId": 93,
  "paragraphs": ["Арабский заголовок из документа", "Первый абзац", "Второй абзац"]
}
```

Огласовки и пунктуация остаются как в присланном тексте. Первым абзацем идёт
заголовок урока. Добавьте в массив `public/text-and-audio/catalog.json` запись:

```json
{
  "lessonId": 93,
  "courseTitle": "Шифахия",
  "duration": 420,
  "audioSrc": "./audio/shifahiya-1/lesson-93.mp3",
  "textSrc": "./text/shifahiya-1/lesson-93.json"
}
```

`courseTitle` — название части в крупном заголовке плеера, без номера части.
Для «Чтения» добавьте `courseId: 2`, укажите `courseTitle: "Чтение"` и пути
в папки `reading-2`. Без `courseId` запись относится к первой части, как раньше.
`duration` — длительность в секундах. Каталог держится в порядке уроков.
Одного аудиофайла недостаточно: кнопка появляется по каталогу после добавления
и записи, и текста. Изменения отправляются отдельной веткой через PR.

## Проверить

```bash
npm test
npm run lint
./node_modules/.bin/tsc --noEmit
npm run build:static
npm run smoke
node scripts/smoke-listening.mjs
node scripts/smoke-listening-catalog.mjs
node scripts/smoke-listening-review.mjs
```

Для браузерных проверок нужен Chromium (`SMOKE_CHROMIUM` задаёт нестандартный путь).
