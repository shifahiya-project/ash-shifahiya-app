# Тексты и записи первой части

Новые материалы хранятся отдельно, по номеру урока:

- `public/audio/shifahiya-1/lesson-91.mp3` — запись;
- `public/text/shifahiya-1/lesson-91.json` — текст;
- `public/text-and-audio/catalog.json` — список доступных пар.

Плеер открывается кнопкой «Текст и аудио» в доступном уроке. Записи и тексты
других уроков при этом не загружаются. Позиция, скорость и настройки текста
сохраняются отдельно для каждого урока. Скачивание урока собирает один HTML
со встроенной записью и текстом; его можно открыть без интернета.
Уроки 87, 88, 91, 92 и 95–100 находятся в общем списке этого плеера.
Первоначальный автономный пилот 87–88 также сохранён по прежнему адресу.

Слова и задания, а также текст и аудио имеют отдельные отметки прохождения.
После занятия нажмите «Текст и аудио пройдены» в плеере. До этого урок остаётся
в компактном списке курса, даже если слова и задания уже пройдены. Отметку можно
отменить. Достижение конца записи само по себе не ставит отметку: текст и аудио
проходятся в своём темпе.

На сайте отметки входят в резервную копию и синхронизацию общего прогресса.
Скачанный HTML сохраняет отметку только в своём браузерном хранилище;
автоматически перенести её на сайт нельзя. После занятия в скачанном файле
отметьте урок отдельно на сайте. Позиции 87–88 из прежнего пилота продолжают
работать в общем плеере, поскольку ключи их хранения совпадают.

## Добавить DOCX и WAV

В корне репозитория, с установленными Python 3 и FFmpeg:

```bash
python scripts/import-listening.py 93 '/path/to/урок 93.docx' '/path/to/урок 93.wav'
```

Скрипт извлекает текст из DOCX без Unicode-нормализации и исправления огласовок,
сохраняет абзацы, пробелы, табуляцию и переносы строк. MP3 кодируется с битрейтом
96 кбит/с, с сохранением каналов исходной записи. Метаданные записи не переносятся.
Существующие уроки не перезаписываются; таблицы, сноски и отслеживаемые удаления
требуют ручной проверки. Исходные документы и WAV остаются у автора, в репозиторий
попадают текст и MP3. При необходимости файлы можно прислать в чат для обработки.

## Загрузить напрямую через GitHub

Загрузите MP3 в папку `public/audio/shifahiya-1` под именем `lesson-93.mp3`.
Добавьте в `public/text/shifahiya-1` файл `lesson-93.json`:

```json
{
  "lessonId": 93,
  "paragraphs": ["Арабский заголовок из документа", "Первый абзац", "Второй абзац"]
}
```

Огласовки и пунктуация остаются как в присланном тексте. Первым абзацем идёт
заголовок урока. Добавьте в массив `public/text-and-audio/catalog.json` запись:

```json
{
  "lessonId": 93,
  "duration": 420,
  "audioSrc": "./audio/shifahiya-1/lesson-93.mp3",
  "textSrc": "./text/shifahiya-1/lesson-93.json"
}
```

`duration` — длительность в секундах. Каталог держится в порядке уроков.
Одного аудиофайла недостаточно: кнопка появляется по каталогу после добавления
и записи, и текста. Изменения отправляются отдельной веткой через PR.

## Проверить

```bash
npm test
npm run lint
./node_modules/.bin/tsc --noEmit
npm run build:static
npm run smoke
node scripts/smoke-listening.mjs
node scripts/smoke-listening-catalog.mjs
```

Для браузерных проверок нужен Chromium (`SMOKE_CHROMIUM` задаёт нестандартный путь).
