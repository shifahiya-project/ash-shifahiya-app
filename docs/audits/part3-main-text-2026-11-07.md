Пользователь прямо указал исключить сноски и примечания из учебных уроков.
Поэтому архивные файлы не скопированы без изменений: убраны нумерованные
сноски, отдельные библиографические блоки и редакторские вставки в оба языка.
Основной текст вокруг вставленных сносок соединён без потери продолжения,
в том числе в 8.5 и 8.17 Бакри. Авторские разделы, ссылки на аяты и короткие
слова, необходимые для русского перевода, сохранены.

Двадцать пар Бакри содержали только сноски и исключены полностью: осталось
666 пар вместо 686. Во всех 37 уроках сохранены номера, названия и порядок.
Все 887 слов сохраняют прежние позиции, семь карточек Курсави исправлены
на месте. Итог — 1213 фрагментов: Бакри 666, Курсави 547.

В 23.28 Курсави архив заменял неподтверждённый перевод редакторским
примечанием о повреждённой фразе. Основной арабский текст сохранён, русское
поле оставлено пустым. Приложение показывает арабский без пустого раскрытия
перевода. Это единственное такое место, проверяемое по точному тексту;
неподтверждённый перевод не восстановлен из предыдущей версии.

## Воспроизведение и прогресс

`npm run part3:review` применяет проверенные правки к имеющимся урокам и
пересобирает манифест. `npm run part3:import -- <словарь.json> <текст.json>`
применяет ту же редакцию при последующих импортах исходных книг.
`npm run part3:import -- --manifest` пересобирает только сводку уроков.

В `scripts/part3-main-text.json` записаны точные удаления и замены;
`scripts/part3-reviewed-text.mjs` проверяет исходные значения и итоговый
отпечаток каждой книги до записи. Повторный запуск уже очищенной редакции
не меняет данные. Другая редакция останавливает импорт для сравнения.

Позиции слов и количество заданий прежние, поэтому ключи повторения,
счёт, доступ к последующим урокам и незавершённые задания не меняются.
Чтение отображается целиком, сессия не запоминает номер фрагмента;
удаление отдельных сносок не требует переноса прогресса.

Проверки `tests/part3-reviewed-text.test.mjs` восстанавливают оба вида входа
(исходный и уже отредактированный), проверяют идемпотентность, отказ на
несовместимой версии без частичной мутации и настоящий повторный импорт
обеих книг с побайтовым сравнением всех уроков и манифеста.
