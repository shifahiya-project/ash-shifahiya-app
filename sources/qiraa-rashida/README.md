# Кыраа рашида

Папка для загрузки книги «Кыраа рашида»: изображений страниц или PDF.

## Как загрузить рисунки

1. Откройте эту папку в GitHub в ветке `book-source`.
2. Выберите **Add file → Upload files**.
3. Перетащите изображения страниц в область загрузки.
4. Нажмите **Commit changes**, сохранив файлы непосредственно в ветку `book-source`.
5. Загружайте партиями до 100 файлов. После каждой партии сохраняйте изменения и повторяйте загрузку в эту же папку.

Один файл при загрузке через сайт GitHub должен быть не больше 25 МБ. Подходят JPG, PNG, WebP и PDF.

Сохраняйте исходное качество и последовательную нумерацию страниц. Если имена уже идут по порядку, менять их не нужно. Загрузите также обложку, титульный лист, оглавление и приложения. Для разных томов используйте отдельные подпапки, например `volume-1/` и `volume-2/`, чтобы одинаковые имена страниц не перезаписывались.
