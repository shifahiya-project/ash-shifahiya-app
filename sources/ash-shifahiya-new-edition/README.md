# Аш-Шифахия — новая версия книги

Папка для исходных изображений страниц новой версии книги.

## Загрузка

1. Откройте эту папку в GitHub в ветке `book-source`.
2. Выберите **Add file → Upload files**.
3. Перетащите изображения или папку с изображениями в область загрузки.
4. Нажмите **Commit changes** и сохраните в ветку `book-source`.

Рекомендуемые имена: `page-001.jpg`, `page-002.jpg`, `page-003.jpg` и далее в порядке книги. Если файлы уже пронумерованы по порядку, переименовывать их не обязательно. Подходят JPG, PNG и WebP. Обложку, титульный лист, оглавление и приложения тоже загружайте.

Для загрузки через сайт GitHub каждый файл должен быть не больше 25 МБ; за одну загрузку можно добавить до 100 файлов. Большую книгу загружайте несколькими партиями.

Это отдельная версия источника. После загрузки нужно уточнить издание и сверить порядок и полноту страниц перед подготовкой учебных материалов.

Исходники остаются в ветке `book-source`; эту ветку не следует объединять с `main`.
