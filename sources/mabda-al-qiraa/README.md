# Мабдауль кыраа

Папка для загрузки книги «Мабдауль кыраа»: PDF или изображений страниц.

## Как загрузить

1. Откройте эту папку в GitHub в ветке `book-source`.
2. Выберите **Add file → Upload files**.
3. Перетащите PDF, изображения или папку с изображениями в область загрузки.
4. Нажмите **Commit changes** и сохраните файлы непосредственно в ветку `book-source`.
5. Если файлов больше 100, загружайте партиями до 100 файлов; после каждой партии сохраняйте изменения, затем повторяйте загрузку в эту же папку.

Для загрузки через сайт GitHub один файл должен быть не больше 25 МБ. Подходят JPG, PNG, WebP и PDF.

Сохраняйте исходное качество и порядок страниц. Рекомендуемые имена изображений: `page-001.jpg`, `page-002.jpg`, `page-003.jpg` и далее. Если страницы уже последовательно пронумерованы, имена можно оставить. Загрузите также обложку, титульный лист, оглавление и приложения.

Это исходные материалы книги. После полной загрузки можно проверить издание, порядок и полноту страниц и использовать их для сверки курса.
