Подробные соглашения — в [CLAUDE.md](./CLAUDE.md). Прочитайте его перед работой:
там модель данных, устройство второй части, подкастов и экзаменов, а также

## Ловушки

**Не правьте генерируемые файлы руками.** Их четыре, и каждый пересобирается
скриптом:

| Файл | Чем пересобрать |
|---|---|
| `content/manifest.ts` | `npm run content:manifest` |
| `content/part2/manifest.ts` | `node scripts/import-part2.mjs <словарь.json> <текст.json>` |
| `content/reading-manifest.ts` | `node scripts/import-reading.mjs <файл.json>` |
| `content/podcasts/catalog.ts` | `YOUTUBE_API_KEY=… npm run podcasts:import` |

Правка урока без пересборки манифеста разойдётся с главной страницей.

**Сборка идёт через `vinext`, а не `next`.** `wrangler.jsonc` не используется:
локальные биндинги описаны в `vite.config.ts`.

**`npm test` уже включает в себя `npm run build`** — отдельно собирать не надо.
Тесты идут под `--experimental-strip-types`, поэтому импорты `.ts`-модулей в них
пишутся **с расширением**: `../app/features.ts`, а не `../app/features`.

**Арабский всегда с полной огласовкой (تشكيل).** И отдельная ловушка: фатха +
шадда и шадда + фатха выглядят одинаково, но это разные последовательности
кодовых точек. Нормальная форма — сначала фатха (U+064E), затем шадда (U+0651).
Регулярку с арабским не набирайте руками — копируйте подстроку из файла урока.

**Ветка `main` защищена**: изменения только через pull request. Прямой push
отклоняется с `GH013`. GitHub Actions выдать bypass нельзя — такого актора нет в
списке.

**Ветка `podcasts/refresh` перезаписывается force-push'ем** каждую неделю
заданием `Refresh podcasts`. На ней нельзя основывать работу.

**Статическая сборка проверяет себя.** `npm run build:static` рендерит обе
страницы и падает, если хоть один адрес ассета не разрешается в существующий
файл. Если правите `scripts/build-static.mjs` — эта проверка там не для красоты:
именно из-за пропущенного адреса страница `/podcasts` однажды рендерилась и
молча не оживала.

## Язык

Интерфейс, учебный контент и общение с пользователем — **по-русски**. Код,
идентификаторы, комментарии в коде и сообщения коммитов — **по-английски**.

## Что не показывается

`app/features.ts` держит два выключателя: `GRAMMAR_ENABLED` и `READING_ENABLED`,
оба `false`. **Так решено, а не отложено:** грамматика и тексты для чтения в том
виде, в каком они написаны, курсу не показываются. Не предлагайте их включить и
не включайте сами.

Данные при этом **не удалены**, и прогресс по ним в хранилище сохраняется —
материал оставлен на случай, если к нему вернутся в другом виде. Подробности
в CLAUDE.md.
